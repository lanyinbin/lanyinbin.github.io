# 汽车车型图片

在此目录放置真实汽车照片，可获得最佳展示效果。

## 支持图片文件

| 文件名 | 车型 |
|--------|------|
| `bmw-x5.png` / `bmw-x5.jpg` | 宝马 X5 |
| `mercedes-s.png` / `mercedes-s.jpg` | 奔驰 S级 |
| `audi-a6.png` / `audi-a6.jpg` | 奥迪 A6 |
| `toyota-prado.png` / `toyota-prado.jpg` | 丰田 普拉多(霸道) |
| `byd-han.png` / `byd-han.jpg` | 比亚迪 汉 |
| `tesla-modely.png` / `tesla-modely.jpg` | 特斯拉 Model Y |

## 图片建议

- 尺寸：建议 800x400 或更高
- 格式：PNG（带透明背景最佳）或 JPG
- 视角：侧面 45度角或正侧面
- 背景：透明或纯色（代码会自动处理）

> 如果没有放置图片，系统将自动使用程序生成的精细车型轮廓图。
